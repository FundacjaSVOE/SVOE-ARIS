# SVOE-ARIS

## Animal Rescue Intelligence System

ARIS is an AI-powered automation system developed for SVOE Foundation animal protection projects.

## Main goals

- Collect animal protection news
- Analyze and filter information
- Generate publications
- Translate content
- Publish to social networks

## Languages

- Polish
- Russian
- English
- German

## Main modules

- Collector
- Analyzer
- Writer
- Translator
- Publisher
